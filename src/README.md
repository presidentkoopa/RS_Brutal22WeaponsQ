# src/

The packs own lumps, unpacked so they are greppable and diffable in git. The meshes are not
duplicated here -- they are in `../models/` and inside the pk3.

| | |
|---|---|
| `bd22/` | everything in `BD22_Models_v9.pk3` except `models/` |
| `vplus/` | everything in `RS_VanillaVRPlus_VR_v9.pk3` except `models/` |
| `v8_questhands/` | the **superseded** v8 generation (`qh_*.zs`) |

## The current generation

```
zscript/rsq/   hands, the per-gun hand table, gun movement, ballistics
zscript/rsr/   the reload: vreload.zs (magazines), rsr_break.zs (break-open and revolvers),
               rsr_pump.zs (pump shotguns), rsr_assist.zs (the capture zones),
               and the generated per-gun tables
zscript/rsvr/  VR plumbing and melee
actors/        the patched DECORATE: each weapon Reload goes to our entry state after all of
               its own checks
MODELDEF.*     one block per drawn piece; a piece is hidden with a clear skin
CVARINFO.*     every cvar
MENUDEF.rsq    Options -> RS VR Hands, Reload, Ballistics
```

Files marked `generated by ... -- do not edit by hand` are regenerated by the tools in
`../tools/`. Where one has been hand-patched anyway, it says so at the top with a date and a
re-apply note -- `rsb_guns.zs` is the live example.

## Two generations, do not mix

Nothing in the shipped packs references a `qh_` class. `v8_questhands/` is kept for its
reasoning only.

**Editing here does not change a pack.** The pk3s in `../packs/` are what ships; this tree is the
readable copy. Patch the pack, then refresh this.
